# Image prompts

One prompt per empty slot on the site. Paste into Gemini (or any image model),
download, then upload through the dashboard.

---

## Read this first

**1. Generate the hero first, then feed it back as a reference.**
Text-to-image will invent a different building every time. Generate `hero-day`,
then attach that image to every other Vantage prompt and add *"match the
building, materials and colour of the attached reference exactly."* Without
this, Tower A looks like a different project in every shot.

**2. Do not generate people's faces.** Leadership portraits must be real
photographs of the real people. Same for anything presented as a testimonial.

**3. These are interim.** For a live RERA-regulated site, the hero and project
images should end up as real photography, or renders from a visualisation
studio working off the actual drawings. A generated building that does not
match the site is the kind of thing a buyer can complain about. Use these to
show the client the layout working, and to brief the photographer.

---

## Style base — paste at the end of every prompt

```
Editorial architectural photography. Full-frame camera, 24mm tilt-shift lens,
verticals corrected. Natural light only, no HDR, no oversaturation. Restrained
premium colour grade, warm neutrals. Contemporary Indian residential
architecture — white concrete, clear glass, dark metal railings, local
landscaping. No text, no logos, no watermarks, no signage lettering, no
distorted faces.
```

### Leadership portraits ×3
`4:5 · 1000 × 1250`

**Do not generate these.** Real photographs of the real people. Brief for the
photographer:

> Head-and-shoulders, standing, three-quarter turn to camera. Plain warm-grey
> or office background, consistent across all three. Soft window light from one
> side. Business formal, no jacket required. Same crop, same distance, same
> background for all three so the row reads as a set.
